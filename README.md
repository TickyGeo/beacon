# Управление яркостью светодиода с помощью ШИМ (PWM)

## 📖 Описание
Этот скетч демонстрирует базовые возможности работы с ШИМ (PWM - широтно-импульсная модуляция) на платах Arduino. Программа ступенчато уменьшает яркость светодиода, подключенного к 3-му пину, переключаясь между 5 заданными уровнями яркости.

## 🛠 Необходимые компоненты
* Плата Arduino (Uno, Nano, Mega и т.д.)
* Светодиод (любого цвета)
* Токоограничивающий резистор (220 Ом - 1 кОм)
* Макетная плата (breadboard) и провода-перемычки

## 🔌 Схема подключения
* **Пин 3 (PWM)** ➔ Резистор (220 Ом) ➔ Анод светодиода (длинная ножка)
* Катод светодиода (короткая ножка) ➔ **GND** (Земля)

> [!NOTE]
> Пин 3 на большинстве плат Arduino поддерживает аппаратный ШИМ, что обычно отмечено символом `~` или надписью `PWM` на самой плате.

## 🚀 Как использовать
1. Соберите схему согласно описанию выше.
2. Подключите Arduino к компьютеру через USB.
3. Откройте файл `.ino` в Arduino IDE.
4. Выберите вашу плату и COM-порт в меню `Инструменты` (Tools).
5. Нажмите кнопку `Загрузить` (Upload).

## 💡 Как это работает?
* `pinMode(3, OUTPUT);` — настраивает 3-й пин как выход для передачи сигнала.
* `analogWrite(3, value);` — генерирует ШИМ-сигнал. Значение `value` может быть от `0` (полностью выключен) до `255` (максимальная яркость).
* В коде задана последовательность изменения яркости: `255` ➔ `200` ➔ `150` ➔ `100` ➔ `40`.
* `delay(500);` — задает паузу в 500 миллисекунд (полсекунды) между изменениями яркости.

## 📈 Идеи для улучшения (Challenge)
Если вы хотите развить этот проект, попробуйте реализовать следующее:
1. Замените последовательные вызовы `analogWrite` на цикл `for` и массив значений.
2. Сделайте так, чтобы яркость не просто падала, а плавно "дышала" (нарастала от 0 до 255 и обратно).
3. Добавьте тактовую кнопку для ручного переключения между уровнями яркости.
